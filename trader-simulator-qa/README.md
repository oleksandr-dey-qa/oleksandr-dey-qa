# 📈 Trader (Spribe) — QA & Player Checklist

Цей репозиторій містить практичний чекліст для безпечної гри та тестування стратегій у симуляторі торгівлі фінансовими активами **Trader** від відомого провайдера **Spribe**.

Проєкт створено для структурування процесу тестування логіки гравця, мінімізації ризиків «зливу» банку та контролю емоційного стану під час гри (тильт-менеджмент).

## 🗂 Структура репозиторію

*   [CHECKLIST.md](./CHECKLIST.md) — безпосередньо сам чекліст у форматі Markdown з інтерактивними чекбоксами.

## 🚀 Як користуватися чеклістом на GitHub

Чекбокси в цьому файлі підтримують інтерактивну відмітку на GitHub: для цього достатньо створити **Issue** та вставити туди вміст чек-листа — тоді кожен пункт `[ ]` стане клікабельним прямо в браузері, і можна буде відмічати виконані кроки прямо під час ігрової сесії.

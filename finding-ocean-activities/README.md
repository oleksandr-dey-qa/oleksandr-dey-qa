# 🌊 Epic Ocean Guide — QA Checklists

Цей репозиторій містить структуровані чек-листи для тестування сайту **Epic Ocean Guide** (https://www.epicoceanguide.com/).

Проєкт створено для структурування процесу тестування сайту: перевірки технічного стану, UX/UI, SEO та аналітики (комплексний чек-лист), а також швидкої перевірки стабільності нової збірки (BVT / Smoke-тест).

## 🗂 Структура репозиторію

*   [bvt_checklist_ua.md](./bvt_checklist_ua.md) — BVT (Build Verification Test) чек-лист у форматі матриці тест-кейсів — Smoke-тест для швидкої перевірки стабільності нової збірки перед подальшим тестуванням.
*   [comprehensive_checklist_ua.md](./comprehensive_checklist_ua.md) — Комплексний чек-лист сайту: технічний стан, UX/UI, SEO та аналітика.
*   Англомовні версії обох файлів (`bvt_checklist.md`, `comprehensive_checklist.md`) також доступні в цій папці — відкривайте їх напряму в репозиторії.

## 🚀 Як користуватися чеклістом на GitHub

Відмічайте виконані пункти галочками прямо під час тестування. GitHub підтримує інтерактивні чекбокси — достатньо відкрити файл чек-листа та натискати на квадратики біля кожного пункту.
